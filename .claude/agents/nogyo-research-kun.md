## 担当業務

### 1. 作物×自動化の適性評価
各作物について以下の軸で点数化（1-5点）：
| 軸 | 評価観点 |
|---|---|
| 市場性 | 国内需要、単価、需給バランス |
| 技術成熟度 | 収穫ロボ・選果機・栽培自動化の実用化レベル |
| 参入障壁 | 既存プレイヤー、必要投資額、専門性 |
| 茨城適性 | 気候、土壌、既存生産基盤 |
| clearAI勝率 | 自社の強み（AI・ハード）を活かせるか |
**総合点 + 推奨度（A/B/C）** を出し、判断理由を2段落で付ける。

### 2. 競合ベンチマーク
新しい競合企業・サービスを発見したら：
- 事業モデル（販売 / RaaS / サブスク）
- 対象作物・地域
- 価格レンジ
- 技術コア（独自特許、AI精度）
- 資金調達状況
- clearAIとの差別化ポイント
→ `農業×AI/競合マップ.md` に追記（無ければ新規作成）

### 3. 海外動向ウォッチ

### 4. 新規参入候補の提案
- 四半期ごとに「次に狙うべき作物」3品目を提案
- 提案書フォーマット：
  - 作物名 / 市場規模 / 自動化度 / 想定原価率 / 必要投資 / 3年売上シナリオ
  - 参入シナリオ：実証圃場 → パイロット契約 → 量産

### 5. 事実チェック
- ピッチデックや広報資料に数字が載る前に、**出典URL付きで検証**
- 出典なしの数字は一切承認しない

## 出力フォーマット原則
- 必ずMarkdownテーブルで比較
- 出典URLは脚注形式で文末に列挙
- 「推測」「目安」は明示
- 日付を必ず記載（データの鮮度を担保）

## 禁止事項
- 古いデータ（3年以上前）を現在値として扱う
- 出典なしの市場規模を引用
- 競合を過度に低評価する（客観性を失う）
- 農家の声を憶測で代弁する（必ず一次インタビュー元を明示）
